# Голос — ежедневная практика

Статический сайт без сборки и зависимостей. 30 занятий: обычные по 24 минуты, облегчённые по 20 минут. Время включает отдых, наблюдения и прослушивание записей в отдельном диктофоне.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий GitHub, например voice-practice.
2. Загрузите файлы index.html, styles.css, app.js и .nojekyll в корень репозитория (не ZIP и не внешнюю папку).
3. Сохраните изменения кнопкой Commit changes.
4. Откройте Settings → Pages.
5. В Build and deployment выберите Deploy from a branch, ветку main и папку / (root). Нажмите Save.
6. Дождитесь завершения публикации. Ссылка появится в Settings → Pages.

## Использование
Откройте день, выполняйте блоки по порядку. У каждого блока есть таймер с паузой и сбросом. Одновременно работает один таймер. При переключении дня таймер сбрасывается.

Кнопка «Завершено» отмечает весь день выполненным и открывает следующий. Предыдущие и будущие дни доступны всегда через номера. Завершённые отмечены галочкой. После дня 30 можно повторять любой день.

Заметки, последний открытый день и отметки сохраняются в localStorage этого браузера. Синхронизации между устройствами нет. Очистка данных сайта или приватный режим могут удалить прогресс. Сброс прогресса удаляет также заметки и требует подтверждения.

Аудиозапись не встроена: используйте диктофон телефона. Таймер не является проверкой выполнения: завершить занятие можно в любой момент. После завершения дня следующую практику можно выполнить завтра.

## Материалы
Тексты учебные, упражнения адаптированы для самостоятельной практики. Основной акцент — голос, свобода звучания и перенос в текст, без публичных выступлений. При боли, головокружении или нарастающей осиплости остановитесь. Не растягивайте челюсть силой и не массируйте гортань.

## Редактирование
Тексты: массив texts в app.js; названия: titles; цели: purposes; слова: words. Оформление: styles.css. Сервер не нужен.
